CAFE PIANO

Cafe Piano is a Persian, responsive landing page for a café inspired by the warm atmosphere of coffee and piano music. The website is built without images and includes an introduction, a categorized menu, a virtual piano, and contact information.

FEATURES

- Persian language and right-to-left layout
- Responsive design for mobile, tablet, and desktop
- Menu categories: coffee, cold drinks, tea and herbal tea, cakes and desserts, breakfast and snacks
- Menu items with descriptions and prices
- Virtual piano playable with a mouse or touch
- Piano-like notes generated using the Web Audio API
- Mobile navigation menu
- Header appearance changes on scroll
- CSS animations and transitions
- No framework or package installation required

The virtual piano audio is generated in the browser and does not use recordings of a real piano.

PROJECT STRUCTURE

cafe-piano/
index.html
style.css
script.js

RUN THE PROJECT

Open the project folder in Visual Studio Code. Install the Live Server extension, if needed. Then right-click index.html and select “Open with Live Server.”

PROJECT FILES

index.html contains the page structure and content.
style.css contains the visual design, responsive layout, and animations.
script.js handles the categorized menu, mobile navigation, header effects, and piano audio.

EDITING THE MENU

Menu items, descriptions, and prices are stored in the menuData section of script.js. The listed prices are examples and can be changed to match the café’s actual menu.
